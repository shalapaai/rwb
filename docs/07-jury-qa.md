# 07 · Вероятные вопросы жюри

> ⚠ **Устарело: модель v2.** 26.11 команда перешла на модель v3 — запас на mesh-полке только из отказов и возвратов. Действующие правила — в [AGENTS.md](../AGENTS.md), разделы 1–2; документ обновляется задачей F6 роадмапа.

На вопросы — 3 минуты, поэтому на каждый нужен ответ с числом из модели. Все числа — наши допущения, не тарифы RWB.

| Вопрос | Ответ |
| --- | --- |
| Вы строите новую логистику? | Нет. Возим теми же газелями, что развозят заказы из хаба по 5–15 ПВЗ. Ночной план добавляет остановку, только когда это дешевле хаба и не больше ~20 мин к рейсу |
| Зачем это владельцу ПВЗ? | +7,8 ₽ с заказа, ~10 тыс. ₽ в месяц при полной полке за ~3 ч работы в день; безубыточность — с 10% загрузки полки |
| Маркетплейс не уходит в минус из-за выплат ПВЗ? | Выплаты ПВЗ и место в газели уже вычтены: маркетплейс +12,3 ₽ на заказ. Безубыточность по потерям ≈ 1,1% |
| Где граница выгодности? | Выгода = цена через хаб − цена варианта − λ·часы. Крюк окупается от ~5 единиц, челнок от ~100, лежание ≤ ~25 дней, товар ≤ 5 л и ≤ 15 000 ₽. Иначе алгоритм сам отправляет через хаб |
| Не помешает ли обычной выдаче? | Полка ≤ 25% объёма, mesh-операции только в окна без очереди, дневной лимит, стоп поставок при заполнении ячеек выдачи > 85% |
| А если товар украдут или потеряют? | Скан каждой операции, ежедневная выборочная инвентаризация, ответственность ПВЗ с потолком; дорогие товары — только в защищённых ПВЗ с сейфом и лимитом 300–500 тыс. ₽ |
| Почему не мини-СЦ в каждом городе? | Это стройка: ~450 тыс. ₽/мес → ~18 ₽ за перемещение против ~7 ₽ попутно. И магистраль он не убирает. В развитии городская точка обмена может стать одним из узлов графа |
| Что с хабом и СЦ? | Проходов через хаб/СЦ на заказ ≈ 0,6 вместо 1. Хаб остаётся для межгорода, крупного, дорогого и редкого товара |
| Как у вас в Йошкар-Оле без своего СЦ? | Путь «через СЦ» здесь — 250–300 км до Зеленодольска или Чебоксар. Поэтому основные варианты — без перевозки и попутные; mesh здесь выгоднее, чем в городе с СЦ |
| Что, если ПВЗ закрылся? | Он выпадает из ночного плана, заказы перемаршрутизируются (сценарий 4), у каждого заказа есть запасной путь через хаб; доп. затраты несёт виновник |
| Чем это лучше FBS? | При FBS товар всё равно идёт через СЦ и собирается под каждый заказ. У нас часть заказов готова через 30 минут, возвраты сразу снова продаются, продавцу не нужен свой склад |
| Откуда выгода — не перекладывание ли денег? | Из внешних затрат, которых не стало: отбор в хабе, сортировки, магистраль. Тест проверяет: сумма выгод сторон = экономия цепочки = разница внешних затрат |
| Насколько это оптимально? | Базовый вариант — жадная вставка пар. Дальше: поток минимальной стоимости по всем заказам сразу, совместная оптимизация маршрутов (ALNS), перевозка заранее в пустом месте газели, управление спросом. Сравниваем три схемы на одном городе |
| Откуда цифры? | Таблица допущений с основанием каждого; публичные ориентиры — только для масштаба; пилот нужен, чтобы замерить время операций и потери |
| Какую долю заказов возьмёт mesh? | Не обещаем. Цель пилота — ≥ 60% заказов допущенных SKU локально; от всех заказов города — прикидка 5–15% на старте |
