# Раскрытие наработок и инструментов

Положение разрешает наработки до хакатона при условии раскрытия (п. 8.2) и «универсальные заготовки» (п. 8.1). ИИ-инструменты разрешены с раскрытием, и каждый участник должен уметь объяснить код, расчёты и архитектуру (п. 8.3).

## Сделано до начала разработки (25.11, первые часы хакатона)

| Что | Где | Предметная логика? |
| --- | --- | --- |
| Исследование задачи и экономическая модель | `docs/` | Описание, не код |
| Docker Compose: PostgreSQL, backend, frontend | `docker-compose.yml` | Нет |
| Каркас FastAPI: конфиг, подключение к БД, JSON-логи, роли, `/health`, `/metrics` | `backend/app/core`, `backend/app/api` | Нет |
| Настройка Alembic без миграций | `backend/migrations` | Нет |
| Оболочка React с переключателем ролей и проверкой API | `frontend/` | Нет |
| CI: линтер и тесты | `.github/workflows/ci.yml` | Нет |

## Пишется на хакатоне

Модель данных и миграции, остатки и резервы, заказы и статусы, маршрутизация, двойная запись, инциденты, длительное хранение, заглушки `/stub/*`, экраны UI, сценарные тесты и отчёт.
