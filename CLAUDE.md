## Только для Claude Code

- **Режим — вайбкодинг по брифу.** Генерировать код целиком можно, если это задача из роадмапа и человек дал её бриф. Без брифа — сначала спросить, какая это задача.
- **Начало задачи:**
  - назвать её номер (`N4`, `M1`…);
  - проверить, что зависимости влиты в `main` (`git log --oneline main`);
  - перечислить файлы, которые будут изменены, и не выходить за папки своей роли (AGENTS.md, раздел 4).
- **Задача больше чем на 3 файла:** сначала короткий план в 5–7 пунктов, потом код.
- **Неясно бизнес-правило** (особенно открытые вопросы из раздела 2) — спросить человека с вариантами ответа, не додумывать.
- **Проверка перед ответом:** `cd backend && pytest -q && ruff check .`; для фронта — `cd frontend && npm run build`. Красное не отдавать: сначала починить или честно сказать, что не работает.
- **Git:**
  - не коммитить и не пушить без прямой просьбы;
  - не делать `git reset --hard`, `push --force` и удаление файлов вне своей задачи.
- **Ответ в конце:** по формату AGENTS.md, раздел 11 — файлы, 5 строк «как работает», как проверить, что не сделано.
