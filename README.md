# Mesh-доставка с хранением в ПВЗ — хакатон RWB

ПВЗ становится городским микроскладом для узкого быстрого ассортимента и возвратов. Mesh-доставка между ПВЗ включается только там, где она дешевле и быстрее хаба. В остальных случаях заказ идёт по базовой схеме через хаб, и система объясняет почему.

| Показатель (городской заказ, на единицу) | База (хаб) | Mesh | Δ |
| --- | --- | --- | --- |
| Себестоимость для цепочки | 69,6 ₽ | 41,3 ₽ | −28,3 ₽ (−41%) |
| Срок до готовности в ПВЗ | 36 ч | 8,5 ч | −27,5 ч (−76%) |
| ПВЗ / продавец / маркетплейс | — | — | +7,9 / +12,8 / +7,6 ₽ |
| Цена для покупателя | — | — | 0 ₽ |

> Все тарифы и затраты — **синтетические допущения модели**, а не действующие тарифы RWB (п. 7.5 положения).

## Статус репозитория

Сейчас здесь **универсальное окружение без предметной логики** (п. 8.1 положения) и проектная документация. Предметный код (остатки, заказы, маршрутизация, проводки, сценарии) команда пишет сама на хакатоне. Что сделано заранее и с помощью каких инструментов, перечислено в [DISCLOSURE.md](DISCLOSURE.md).

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
```

| Сервис | Адрес |
| --- | --- |
| Frontend (React + Vite) | http://localhost:5173 |
| Backend API | http://localhost:8000 |
| Swagger / OpenAPI | http://localhost:8000/docs |
| Health | http://localhost:8000/health |
| PostgreSQL | localhost:5432 (`mesh` / `mesh`) |

Если порт занят, поменяйте `DB_PORT`, `API_PORT` или `WEB_PORT` в `.env`.

Локально без Docker: `make backend-dev` и `make frontend-dev` (нужна запущенная БД: `docker compose up db`). Все команды: `make help`.

## Стек

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, pytest
- **Frontend:** React 18, Vite, TypeScript
- **Инфраструктура:** Docker Compose, GitHub Actions (линтер и тесты)

## Главное для защиты

1. **Показываем, когда mesh не нужен.** Рейс курьера окупается от 74 ед. (против хаба) и от 104 ед. (против СЦ с учётом времени). Недостачи — не выше 0,8%. Крупногабарит и редкий спрос остаются в хабе.
2. **Деньги сходятся до копейки, и это проверяет код.** Двойная запись и тест: сумма выгод сторон = экономия цепочки = разница внешних затрат.
3. **Возвраты остаются в городе** и сразу снова продаются.
4. **Стресс-тесты ломают модель, правила её чинят.** Пример: надбавка за залёживание возвращает маркетплейс в плюс.
5. **Продолжаем то, что RWB уже делает:** партнёрские хабы, пункты приёма товаров, перепродажа невыкупов в ПВЗ.
