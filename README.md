# Mesh-доставка с хранением в ПВЗ — хакатон RWB

Храним ходовой товар в ПВЗ и возим его между пунктами попутно, теми же газелями, что развозят заказы из хаба. Остановку в маршрут добавляем, только когда это дешевле хаба. Иначе заказ идёт по базовой схеме через хаб, и система показывает почему.

## Допущения

Все тарифы — синтетические допущения модели по п. 7.5 положения. Основания и единицы измерения каждого параметра доступны в [GET /model/params](http://localhost:8000/model/params). На запущенном стенде каталог можно получить командой `curl -H 'X-Role: admin' http://localhost:8000/model/params`.

| Параметр v3 | Значение | Поле в каталоге |
| --- | ---: | --- |
| Ожидание отказа на полке до решения о вывозе | 14 суток | `shelf_days` |
| Базовая доля склада ПВЗ под mesh | 25% | `mesh_share_pct` |
| Объём единицы / базовый спрос на неё | 2 л / 1 ед. в сутки | `volume_l`, `demand_per_day` |
| Проверка отказа / дополнительная работа с упаковкой B | 3 мин / 2 мин | `inspection_min`, `repack_min` |
| Хранение за литр в сутки (место + труд + прибыль ПВЗ) | 0,05 + 0,05 + 0,05 = 0,15 ₽ | `space_kop_l_day`, `shelf_labour_kop_l_day`, `shelf_profit_kop_l_day` |
| Возврат отказа в хаб / следующий заказ из хаба | 37,00 ₽ / 60,40 ₽ | `hub_return_kop`, `hub_order_kop` |

В v3 полку пополняет отказ **при получении**. Возврат **после выдачи** едет в хаб. Для защиты используйте расчёт на одну пригодную единицу и пять сценариев v3. Таблица в архиве и прежние пороги в разделе «Главное для защиты» относятся к v2. [Бизнес-модель](docs/02-business-model.md) · [Сценарии](docs/04-scenarios.md)

## Главное для защиты

1. **Никакой новой логистики.** Те же газели, что объезжают 5–15 ПВЗ; ночной план добавляет пару «забрать в А → отдать в Б», только если это дешевле хаба и не больше ~20 мин к рейсу.
2. **Граница выгодности на числах.** Крюк окупается от ~5 единиц, челнок от ~100, потери до ≈ 1,1%, товар ≤ 5 л и ≤ 15 000 ₽, лежание ≤ ~25 дней. Иначе — хаб, с причиной.
3. **Деньги сходятся до копейки, и это проверяет код.** Двойная запись и тест: сумма выгод сторон = экономия цепочки = разница внешних затрат. Выплаты ПВЗ уже вычтены из экономии маркетплейса.
4. **Возвраты остаются в городе** и сразу снова продаются.
5. **Хаб разгружается:** ≈ 0,6 прохода через хаб/СЦ на заказ вместо 1.
