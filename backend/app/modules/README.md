# Предметные модули

Каркасы всех модулей созданы, роутеры подключены в `app/main.py`, модели импортированы в `migrations/env.py` — эти файлы при работе над модулем трогать не нужно. Владельцы и правила — [AGENTS.md](../../../AGENTS.md), раздел 4.

| Модуль | Префикс API | Владелец | Задачи | Статус |
| --- | --- | --- | --- | --- |
| `routing` | `/routing` | — | — | Готов: ночной план газелей, дневной выбор варианта, закрытие ПВЗ, сравнение схем, 22 теста |
| `network` | — | У1 | N2 | Каркас |
| `inventory` | `/pvz` | У1 | N4 | Каркас |
| `ledger` | `/ledger` | У1 | N3 | Каркас |
| `orders` | `/orders` | У1 | M1, F1 | Каркас |
| `stubs` | `/stub` | У1 | M2 | Каркас |
| `analytics` | `/analytics` | У1 | M2 | Каркас |
| `ops` | — | У1 | F1 | Каркас |
| `scenarios` | `/scenarios` | У1 | F2 | Каркас |
| `economics` | `/model` | У3 | N8, N9, M5 | Каркас |

Состав модуля: `models.py` (ORM, наследуются от `app.core.db.Base`), `schemas.py` (Pydantic), `service.py` (логика без FastAPI), `router.py` (эндпоинты); тесты — `backend/tests/<модуль>/`.

Деньги — только в копейках (`int`), начисления — только через `ledger.post`.
