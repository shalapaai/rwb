# Предметные модули

Реализовано:

- **`routing`** — алгоритм логистики: ночной план газелей и дневной выбор варианта.
  - `models.py` — входы и выходы, параметры модели v2 (копейки, минуты);
  - `network.py` — граф «дешёвых» рёбер и поток минимальной стоимости по артикулу;
  - `nightly.py` — целевой запас, вставка остановок с лимитами, повторы;
  - `daily.py` — выбор варианта для нового заказа с причинами, закрытие ПВЗ;
  - `compare.py` — три схемы на одних заказах;
  - `demo.py` — синтетический город; `router.py` — API `/routing/*`.

Остальные модули пишутся на хакатоне.

Планируемые модули и их ответственность — в [docs/03-architecture.md](../../../docs/03-architecture.md#модули-backend):
`network`, `inventory`, `orders`, `routing`, `ledger`, `ops`, `stubs`.

Соглашения для каждого модуля:

- `models.py` — ORM-модели (наследуются от `app.core.db.Base`);
- `schemas.py` — Pydantic-схемы запросов и ответов;
- `service.py` — бизнес-логика без FastAPI;
- `router.py` — эндпоинты, подключаются в `app/main.py`;
- тесты — в `backend/tests/<модуль>/`.

Деньги — только в копейках (`int`), начисления — только через одну функцию проводки.
